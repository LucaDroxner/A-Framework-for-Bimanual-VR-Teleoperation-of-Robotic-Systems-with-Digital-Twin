## Demo Videos

This repository contains demonstration videos illustrating the functionality of the VR teleoperation framework:

* **Physical Hardware Teleoperation:** Demonstrates real-time bimanual teleoperation on the physical dual-arm setup (UR15).
* **Digital Twin Teleoperation:** Demonstrates teleoperation within the Unity-based simulation environment.

> **Note:** The provided recordings depict representative demonstration runs showing identical system behavior and features, but are not the exact experimental trials reported in the paper.
