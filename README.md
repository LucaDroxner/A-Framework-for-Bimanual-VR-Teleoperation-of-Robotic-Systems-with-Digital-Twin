## Demo Videos

This repository contains video demonstrations illustrating the functionality of the VR teleoperation framework:

* 🎬 **[Physical Hardware Teleoperation](https://github.com/LucaDroxner/A-Framework-for-Bimanual-VR-Teleoperation-of-Robotic-Systems-with-Digital-Twin/releases/download/v1.0.0/VRTeleoperation_PhysiscalHardware.mov)** (211 MB): Real-time bimanual teleoperation on physical hardware (dual-arm UR15 setup) using Meta Quest 3 hand tracking.
* 🎬 **[Digital Twin Teleoperation](https://github.com/LucaDroxner/A-Framework-for-Bimanual-VR-Teleoperation-of-Robotic-Systems-with-Digital-Twin/releases/download/v1.0.0/VR_Teleop_DigitalTwin.mov)** (30.6 MB): Bimanual teleoperation and hybrid control execution within the Unity-based digital twin environment.

> **Note:** The provided recordings depict representative demonstration runs showing identical system behavior and features, but are not the exact experimental trials reported in the paper.
